## 📖 Overview

A local browser playground for the VisualViewport API. It displays visual viewport size, scale, offsets, and page coordinates beside the layout viewport measurements. Try scrolling, pinch zoom, or focusing the demo input on a mobile device.

## ✨ Features

- 📐 Compare layout and visual viewport dimensions
- 🔍 Watch scale and offset values change
- 📱 Try pinch zoom and mobile keyboard behavior
- 📈 Update on window and visualViewport events
- 🔒 No telemetry or remote requests

## 🖥️ Demo

No hosted demo is claimed. Run the project locally using the steps below.

## 🚀 Quick Start

```bash
npm start
# Open http://127.0.0.1:4173
```

Node.js 18+ local static server; browser-native VisualViewport API.
